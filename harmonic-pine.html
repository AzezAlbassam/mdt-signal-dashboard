//
//   · THE BEST PATTERN FOUND BY SEARCH DID NOT SURVIVE. On half the symbols, Three Drives on
//     4h hit its first target 68.8% of the time. Re-tested on the other half — never looked

//     chart table below is the same machine that produced that number, which is why it
//     prints a sample size and a confidence interval beside every win rate.
//
// What the whole sample looks like: the first target is reached 31.1% of the time and the
// MEDIAN trade is exactly -1R, usually stopped on the bar it was entered, because the far
// edge of the zone sits close to the near edge. A high hit rate is not an edge: 5-0 reaches
// its target 57-60% of the time on every timeframe and still averages about -0.30R, because
// its wins are small and its losses are whole.
//
// Two post-hoc fixes are on the record, both found after the first run and both disclosed
// with before/after numbers in reports/harmonic-prefix/. The second one moved a verdict: it
// removed 314 5-0 "trades" whose first target sat on the wrong side of the entry, and H1
// went from not confirmed to confirmed. A confirmation that arrives only after a bug fix is
// weaker than one that arrives clean, and it is reported that way rather than polished.
//
// Full numbers: reports/harmonic.txt.
// ─────────────────────────────────────────────────────────────────────────────────────────
//
// HOW IT WORKS, AND WHY IT DOES NOT REPAINT
// Swings come from a zigzag whose threshold is a multiple of ATR(14), so one setting works on
// a monthly chart and a 5-minute one. A pivot is only published on the bar that CONFIRMS it,
// and is never revised. A pattern is registered the moment its second-to-last pivot confirms,
// which is when X, A, B and C are all known — so the PRZ, the entry, the stop and the targets
// are all computable before D exists, and none of them ever moves afterwards. That is what a
// harmonic trader actually does: a limit order into the zone. Scripts that wait for D to
// confirm are late; scripts that redraw D as price moves are repainting.
//
// READING THE CHART
// The coloured box is where to buy (green) or sell (red). It is drawn from the bar the
// pattern confirmed — not from point C, which is older than the signal — to the last bar on
// which a touch still counts, and it stops there. So the box's two ends are the two dates
// that matter: when the setup became knowable, and when it dies. The label on it names the
// side, the pattern and the zone, and then says which of four things happened:
//
//   waiting      price has not reached the zone yet and the window is still open
//   TRIGGERED    price reached the zone: the limit order would have filled here
//   VOID         price broke point C first, or jumped the whole zone in one bar
//   EXPIRED      the window closed and price never got there
//
// A void or expired setup turns grey and keeps its place, because how often these never
// arrive is part of the picture; "Hide patterns once they are void" removes them. The key in
// the bottom-left corner names every line and box on the chart.
//

// ─────────────────────────────────────────────────────────────────────── the ratio table
// Published windows, PROTOCOL-harmonic.md §1.5. A single number carries the tolerance; a
// range is used as published. Everything is evaluated in "v-space" (v = s * price, s = +1 for
// a bullish setup), where the completion point is always a low and every rule is written once.
lo_(float r) => r * (1 - TOL)
hi_(float r) => r * (1 + TOL)
inR(float x, float a, float b) => x >= a and x <= b

        line.delete(array.shift(skel))
    while array.size(draws) > n

// Draw one detected pattern: exactly `np` pivots, so a three-pivot AB=CD does not get a
// fourth leg drawn onto it. Prices are real prices, already out of v-space.
//
// The zone box runs from THIS bar — the bar the structure confirmed and the setup became
// knowable — to the last bar on which a touch still counts. It is not anchored to point C,
// which is older than the signal, and it does not extend forever to the right: both of those
// make the chart lie about when the setup started and when it dies.
drawPattern(string nm, int dirn, int np, float zLo, float zHi) =>
    col = dirn == 1 ? bullCol : bearCol
    int n = array.size(pvP)
    int firstB = array.get(pvB, n - np)
    float firstP = array.get(pvP, n - np)
    int lastB = array.get(pvB, n - 1)
    float lastP = array.get(pvP, n - 1)
    // the same window the backtest gives this pattern, clamped to what Pine will draw ahead
    int expiry = bar_index + 1 + math.max(10, lastB - firstB)
    int right  = math.min(expiry, bar_index + 480)
    float near = dirn == 1 ? zHi : zLo
    float far  = dirn == 1 ? zLo : zHi
    if showSkel
        for i = n - np to n - 2
            array.push(skel, line.new(array.get(pvB, i), array.get(pvP, i), array.get(pvB, i + 1), array.get(pvP, i + 1), color = col, width = 2))
        array.push(skel, line.new(firstB, firstP, lastB, lastP, color = color.new(col, 80), style = line.style_dotted))
    box bx = na
    if showZone
        bx := box.new(bar_index, zHi, right, zLo, border_color = color.new(col, 30),
             border_width = 1, bgcolor = color.new(col, 88))
    string head = (dirn == 1 ? L("شراء", "BUY") : L("بيع", "SELL")) + " " + nm + "\n" +
         str.tostring(zLo, format.mintick) + " – " + str.tostring(zHi, format.mintick)
    string wait0 = L("بانتظار وصول السعر", "waiting for price")
    label lb = label.new(bar_index, near, head + "\n" + wait0,
         style = label.style_label_left, color = color.new(col, 15), textcolor = color.white,
         size = size.small, textalign = text.align_left)
    array.push(draws, Draw.new(bx, lb, head, bar_index + 1, expiry, lastP, near, far, dirn, false, wait0))
    trimTo(keepN)

// The scan runs only when a pivot has just confirmed — a few percent of bars — which is what
// keeps a many-pattern search inside Pine's execution budget.
if newPivot and array.size(pvP) >= 3
    int n = array.size(pvP)
    float s = array.get(pvK, n - 1) == 1 ? 1.0 : -1.0   // completion is always a low in v-space
    int dirn = s == 1.0 ? 1 : -1

    // last four pivots in v-space (X A B C); v3 is the pivot just confirmed
    float v3 = s * array.get(pvP, n - 1)
    float v2 = n >= 2 ? s * array.get(pvP, n - 2) : na
    float v1 = n >= 3 ? s * array.get(pvP, n - 3) : na
    float v0 = n >= 4 ? s * array.get(pvP, n - 4) : na
    float vm1 = n >= 5 ? s * array.get(pvP, n - 5) : na

    float zLo = na
    float zHi = na
    string nm = ""

    // narrow a running zone by one projection: level = ref - [a,b] * base
    // (kept as plain arithmetic because Pine has no closures over mutable locals)
    if n >= 4 and not na(v0)
        float XA = math.abs(v1 - v0)
        float AB = math.abs(v2 - v1)
        float BC = math.abs(v3 - v2)
        float XC = math.abs(v3 - v0)
        float rB = XA > 0 ? AB / XA : na
        float rC = AB > 0 ? BC / AB : na
        bool  bHoldsX = v2 > v0
        bool  cBelowA = v3 < v1

        // every pattern: zone = overlap of its XA window and its BC window (plus AB=CD if asked)
        float a1 = na
        float b1_ = na
        float a2 = na
        float b2_ = na
        float a3 = na
        float b3_ = na
        if useGartley and bHoldsX and cBelowA and XA > 0 and AB > 0 and inR(rB, lo_(0.618), hi_(0.618)) and inR(rC, 0.382, 0.886)
            a1 := v1 - hi_(0.786) * XA, b1_ := v1 - lo_(0.786) * XA
            a2 := v3 - 1.618 * BC,      b2_ := v3 - 1.13 * BC
            a3 := v3 - hi_(1.0) * AB,   b3_ := v3 - lo_(1.0) * AB
            nm := "Gartley"
        else if useBat and bHoldsX and cBelowA and XA > 0 and AB > 0 and inR(rB, 0.382, 0.50) and inR(rC, 0.382, 0.886)
            a1 := v1 - hi_(0.886) * XA, b1_ := v1 - lo_(0.886) * XA
            a2 := v3 - 2.618 * BC,      b2_ := v3 - 1.618 * BC
            a3 := v3 - hi_(1.27) * AB,  b3_ := v3 - lo_(1.27) * AB
            nm := "Bat"
        else if useAltBat and bHoldsX and cBelowA and XA > 0 and AB > 0 and rB <= 0.382 and inR(rC, 0.382, 0.886)
            a1 := v1 - hi_(1.13) * XA,  b1_ := v1 - lo_(1.13) * XA
            a2 := v3 - 3.618 * BC,      b2_ := v3 - 2.0 * BC
            a3 := v3 - hi_(1.618) * AB, b3_ := v3 - lo_(1.618) * AB
            nm := "Alt Bat"
        else if useButter and bHoldsX and cBelowA and XA > 0 and AB > 0 and inR(rB, lo_(0.786), hi_(0.786)) and inR(rC, 0.382, 0.886)
            a1 := v1 - hi_(1.27) * XA,  b1_ := v1 - lo_(1.27) * XA
            a2 := v3 - 2.24 * BC,       b2_ := v3 - 1.618 * BC
            a3 := v3 - hi_(1.27) * AB,  b3_ := v3 - lo_(1.27) * AB
            nm := "Butterfly"
        else if useCrab and bHoldsX and cBelowA and XA > 0 and AB > 0 and inR(rB, 0.382, 0.618) and inR(rC, 0.382, 0.886)
            a1 := v1 - hi_(1.618) * XA, b1_ := v1 - lo_(1.618) * XA
            a2 := v3 - 3.618 * BC,      b2_ := v3 - 2.618 * BC
            a3 := v3 - hi_(1.618) * AB, b3_ := v3 - lo_(1.27) * AB
            nm := "Crab"
        else if useDeep and bHoldsX and cBelowA and XA > 0 and AB > 0 and inR(rB, lo_(0.886), hi_(0.886)) and inR(rC, 0.382, 0.886)
            a1 := v1 - hi_(1.618) * XA, b1_ := v1 - lo_(1.618) * XA
            a2 := v3 - 3.618 * BC,      b2_ := v3 - 2.24 * BC
            a3 := v3 - hi_(1.272) * AB, b3_ := v3 - lo_(1.272) * AB
            nm := "Deep Crab"
        else if useCypher and bHoldsX and v3 > v1 and XA > 0 and inR(rB, 0.382, 0.618) and inR(XC / XA, 1.272, 1.414)
            // the Cypher is the odd one: C breaks past A, and D is measured off XC, not XA
            a1 := v3 - hi_(0.786) * XC, b1_ := v3 - lo_(0.786) * XC
            a2 := a1, b2_ := b1_
            a3 := a1, b3_ := b1_
            nm := "Cypher"
        else if useShark and v3 > v1 and XA > 0 and inR(AB / XA, 1.13, 1.618)
            // Carney's 0-X-A-B: the zone is the overlap of the AB projection and the 0X band
            float OX = math.abs(v1 - v0)
            a1 := v1 - 1.13 * OX,  b1_ := v1 - 0.886 * OX
            a2 := v3 - 2.24 * AB,  b2_ := v3 - 1.618 * AB
            a3 := a1, b3_ := b1_
            nm := "Shark"
        else if useFiveO and v2 < v0 and XA > 0 and AB > 0 and inR(AB / XA, 1.13, 1.618) and inR(BC / AB, 1.618, 2.24)
            a1 := v3 - hi_(0.5) * BC, b1_ := v3 - lo_(0.5) * BC
            a2 := v3 - hi_(1.0) * AB, b2_ := v3 - lo_(1.0) * AB
            a3 := a1, b3_ := b1_
            nm := "5-0"

        if nm != ""
            float z1 = math.max(a1, a2)
            float z2 = math.min(b1_, b2_)
            if needABCD and nm != "Cypher" and nm != "Shark" and nm != "5-0"
                z1 := math.max(z1, a3)
                z2 := math.min(z2, b3_)
            if z1 <= z2
                zLo := z1
                zHi := z2

    // three-pivot AB=CD
    if nm == "" and useABCD and n >= 3 and not na(v1)
        float AB = math.abs(v2 - v1)
        float BC = math.abs(v3 - v2)
        float rC = AB > 0 ? BC / AB : na
        if v3 < v1 and AB > 0 and inR(rC, 0.382, 0.886)
            float z1 = math.max(v3 - hi_(1.0) * AB, v3 - 2.618 * BC)
            float z2 = math.min(v3 - lo_(1.0) * AB, v3 - 1.13 * BC)
            if z1 <= z2
                zLo := z1
                zHi := z2
                nm := "AB=CD"

    // five-pivot Three Drives
    if nm == "" and useDrives and n >= 5 and not na(vm1)
        float d1 = math.abs(v0 - vm1)
        float r1 = math.abs(v1 - v0)
        float d2 = math.abs(v2 - v1)
        float r2 = math.abs(v3 - v2)
        if d1 > 0 and r1 > 0 and d2 > 0 and inR(r1 / d1, 0.618, 0.786) and inR(d2 / r1, 1.27, 1.618) and inR(r2 / d2, 0.618, 0.786)
            float z1 = v3 - 1.618 * r2
            float z2 = v3 - 1.27 * r2
            if z1 <= z2
                zLo := z1
                zHi := z2
                nm := "Three Drives"

    if nm != "" and not na(zLo) and not na(zHi)
        // out of v-space
        float pLo = s == 1.0 ? zLo : -zHi
        float pHi = s == 1.0 ? zHi : -zLo
        float near = s == 1.0 ? pHi : pLo        // the edge price reaches first
        float far  = s == 1.0 ? pLo : pHi
        // The AD leg is measured from A — the run's second-from-last-but-two pivot, which is
        // array index n-3 for every pattern drawn here.
        float aPrice = array.get(pvP, n - 3)
        float ad = math.abs(aPrice - near)
        // The AD leg can invert — the 5-0 completes at 50% of a BC leg that already
        // overshot, so D often lands beyond A. The targets are retracements of AD, so an
        // inverted leg would put the first target on the wrong side of the entry. There is
        // no definable target, so there is no setup.
        bool okTarget = dirn == 1 ? aPrice > near : aPrice < near
        if okTarget
            curName  := nm
            curDir   := dirn
            curNear  := near
            curFar   := far
            curEntry := near
            curStop  := far - dirn * 0.25 * atr
            curT1    := near + dirn * 0.382 * ad
            curT2    := near + dirn * 0.618 * ad
            curT3    := array.get(pvP, n - 1)
            curT4    := aPrice
            curBar   := bar_index
            curArmed := true
            int np = nm == "AB=CD" ? 3 : nm == "Three Drives" ? 5 : 4
            if n >= np
                drawPattern(nm, dirn, np, pLo, pHi)
        // Registered even when the zone-edge target looks inverted: the fill-time test above
        // is the one that decides, and a gap into the zone can make the leg valid.
        if btOn
            int pid = array.indexof(PATS, nm)
            if pid >= 0
                int npb = nm == "AB=CD" ? 3 : nm == "Three Drives" ? 5 : 4
                int xBar = array.get(pvB, n - npb)
                int cBar = array.get(pvB, n - 1)
                array.push(pend, Pend.new(pid, dirn, near, far, array.get(pvP, n - 1), aPrice,
                     bar_index + 1, bar_index + 1 + math.max(10, cBar - xBar), false, na, na, na, na))
                if array.size(pend) > 60
                    array.shift(pend)

// ──────────────────────────────────────────────────────── backtest on this chart
// Replays every registered pattern forward under the frozen rules, so the table below is
// this symbol's own record rather than the study's average. It is the same machine that
// produced the study's winner's curse, so it prints its sample size next to every number.

if btOn and array.size(pend) > 0
    for i = array.size(pend) - 1 to 0
        Pend q = array.get(pend, i)
        if bar_index >= q.startBar
            if not q.filled
                // waiting for the zone
                bool brokeC = q.dirn == 1 ? high > q.cPrice : low < q.cPrice
                bool touched = q.dirn == 1 ? low <= q.near : high >= q.near
                bool gapped  = q.dirn == 1 ? open < q.far : open > q.far
                if brokeC or bar_index > q.expiry
                    array.remove(pend, i)
                else if touched and gapped
                    array.remove(pend, i)               // the bar jumped the whole zone: no entry
                else if touched
                    float fill = q.dirn == 1 ? math.min(q.near, open) : math.max(q.near, open)
                    float a = nz(atr[1], atr)
                    float st = q.far - q.dirn * 0.25 * a
                    float risk = math.abs(fill - st)
                    // The AD leg is measured from the ACTUAL fill, which a gap into the zone
                    // can improve. A non-positive leg means the first target would sit on the
                    // wrong side of the entry, so there is no trade.
                    float span = q.dirn * (q.aPrice - fill)
                    if risk > 0 and span > 0
                        q.entry := fill
                        q.stop := st
                        q.t1 := fill + 0.382 * (q.aPrice - fill)
                        q.filled := true
                        q.entryBar := bar_index
                    else
                        array.remove(pend, i)
            if q.filled
                float risk = math.abs(q.entry - q.stop)
                bool hitStop = q.dirn == 1 ? low <= q.stop : high >= q.stop
                bool hitT1   = q.dirn == 1 ? high >= q.t1 : low <= q.t1
                float r = na
                bool done = false
                if hitStop                                   // stop first: one bar can cover both
                    r := -1.0
                    done := true
                else if hitT1
                    r := math.abs(q.t1 - q.entry) / risk
                    done := true
                else if bar_index >= q.entryBar + btHorizon
                    r := q.dirn * (close - q.entry) / risk
                    done := true
                if done
                    array.set(btN, q.pid, array.get(btN, q.pid) + 1)
                    if hitT1 and not hitStop
                        array.set(btW, q.pid, array.get(btW, q.pid) + 1)
                    array.set(btR, q.pid, array.get(btR, q.pid) + r)
                    array.remove(pend, i)

// it, and if not, why not. Order matters and matches the backtest exactly — a break of C or
// a closed window kills the setup even on a bar that also touches the zone.

            bool gapped  = d.dirn == 1 ? open < d.far : open > d.far

            if broke or over or touched
                d.settled := true
                color c = live ? (d.dirn == 1 ? bullCol : bearCol) : deadCol
                string tail = live     ? L("تفعّل — السعر دخل المنطقة", "TRIGGERED — price reached the zone")
                     : broke           ? L("لاغٍ — كسر النقطة C قبل الوصول", "VOID — broke point C first")
                     : over            ? L("انتهى — أقفلت النافذة بلا وصول", "EXPIRED — window closed, never reached")
                     :                   L("لاغٍ — قفزت الشمعة فوق المنطقة كاملة", "VOID — the bar jumped the whole zone")
                d.state := tail
                label.set_text(d.l, d.head + "\n" + tail)
                label.set_color(d.l, color.new(c, live ? 15 : 55))
                if not na(d.b)
                    box.set_bgcolor(d.b, color.new(c, live ? 85 : 94))
                    box.set_border_color(d.b, color.new(c, live ? 30 : 70))
                    // A dead setup's window is over: end the box where it actually ended,
                    // rather than leaving it stretched over bars it no longer governs.
                    if not live
                        box.set_right(d.b, math.max(bar_index, box.get_left(d.b) + 1))
                if hideDead and not live
                    label.delete(d.l)
                    if not na(d.b)
                        box.delete(d.b)

// ────────────────────────────────────────── the accuracy table for THIS symbol and frame
// Win rate, its 95% Wilson interval, and average R per pattern. The interval is here because
// a win rate without one is the single easiest number in trading to fool yourself with: in
// the study a cell read 68.8% on 32 trades and 57.6% on the next 33.
wilsonLo(int k, int n) =>
    float z = 1.96
    float pp = k / math.max(n, 1)
    float den = 1 + z * z / n
    float c = (pp + z * z / (2 * n)) / den
    float sp = (z / den) * math.sqrt(pp * (1 - pp) / n + z * z / (4 * n * n))
    math.max(0.0, c - sp)
wilsonHi(int k, int n) =>
    float z = 1.96
    float pp = k / math.max(n, 1)
    float den = 1 + z * z / n
    float c = (pp + z * z / (2 * n)) / den
    float sp = (z / den) * math.sqrt(pp * (1 - pp) / n + z * z / (4 * n * n))
    math.min(1.0, c + sp)

قراءة الشارت

كل ما يرسمه المؤشر مشروح في مفتاح صغير أسفل يسار الشارت، وهذا هو:

▬أضلاع النموذج X A B C. ┈ضلع XA المرجعي الذي تُقاس عليه النسب. ▭البوكس هو مكان الأمر. أخضر = منطقة شراء، أحمر = منطقة بيع. يبدأ من الشمعة التي تأكّد فيها النموذج — لا من النقطة C، لأن C أقدم من الإشارة — وينتهي عند آخر شمعة يُحتسب فيها الوصول. فطرفا البوكس هما التاريخان المهمّان: متى صار النموذج معلوماً، ومتى يموت. ▬خط الدخول: أمر محدَّد عند الحافة القريبة من البوكس. ╌الوقف: 0.25 من ATR خلف الحافة البعيدة. ┈الأهداف الأربعة. الاختبار يخرج عند الهدف الأول، وأرقام اللوحة كلها محسوبة عليه. ■الرمادي: النموذج لاغٍ — لم يصل إليه السعر قبل أن تُقفل النافذة.

وعلى البوكس نفسه مكتوب الاتجاه واسم النموذج والمنطقة، ثم حالته، وهي واحدة من أربع:

  • بانتظار وصول السعر — النافذة ما زالت مفتوحة ولم يصل بعد.
  • تفعّل — السعر دخل المنطقة: هنا كان الأمر المحدَّد سينفّذ.
  • لاغٍ — كسر النقطة C قبل أن يصل، أو قفزت شمعة فوق المنطقة كاملة.
  • انتهى — أُقفلت النافذة ولم يصل.

النماذج اللاغية تبقى رمادية على الشارت عن قصد: نسبة ما لا يصل إليه السعر جزء من الصورة. لإخفائها: الإعدادات ← Display ← Hide patterns once they are void. ولعرض الكتابة بالإنجليزية إن لم تُرسم العربية عندك بشكل صحيح: أطفئ Arabic text on the chart.

«سقف الصفقة» هو ما تساويه ٦٠ شمعة من تقويم فعلي. «انتظار الدخول» هو الوقت الميّت بين تأكّد النموذج ولمس السعر للمنطقة. أرقام 1h و4h مقرّبة لليوم الكامل لأن تواريخ تلك السلاسل بلا ساعات، فما يحدث داخل الجلسة يُقرأ صفراً.

إطفاء النماذج التي لا تريدها

في الإعدادات ← مجموعة Patterns إحدى عشرة خانة. أطفئ الكل وأبقِ ما تريد:

Gartley · Bat · Alt Bat · Butterfly · Crab · Deep Crab · Cypher · Shark · 5-0 · AB=CD · Three Drives

AB=CD مطفأ افتراضياً: يحتاج ثلاث نقاط ونسبة واحدة فقط، فيظهر أكثر من كل الباقي مجتمعاً (٧١٪ من كل الاكتشافات في الدراسة). Three Drives هو الأندر والأعلى نسبةً، وعيّنته صغيرة دائماً.

لوحة الدقة على شارتك

تعيد تشغيل قواعد الدراسة نفسها على تاريخ الرمز المفتوح، وتطبع لكل نموذج: عدد الصفقات، نسبة الوصول للهدف الأول، مجال الثقة ٩٥٪، ومتوسط R.

قورنت هذه اللوحة بمحرّك الدراسة على ١٨٧ سلسلة و١٩٬٨٨٦ صفقة: تطابق تام، صفقة بصفقة. فالرقم على شارتك هو نفس الرقم الذي تنتجه الدراسة.

الفخّ الذي بُنيت اللوحة لتحذّرك منه. حين ترى نموذجاً بنسبة ٨٨٪، انظر أولاً إلى عدد الصفقات ومجال الثقة بجانبها. في هذه الدراسة بالذات: خانة قرأت ٦٨.٨٪ على ٣٢ صفقة، ثم على ٣٣ صفقة من أسهم لم تُفتح من قبل قرأت ٥٧.٦٪ وخسارة. لذلك يظهر الرقم بالرمادي تحت ٣٠ صفقة، وبجانبه دائماً مجاله. ونسبة عالية مع R سالب = فخّ: نموذج ٥-٠ يصل هدفه ٥٧–٦٠٪ ومتوسطه حوالي −0.30R، لأن أرباحه صغيرة وخسائره كاملة.

إعدادات تغيّر المؤشر عن الذي اختُبر

  • Swing size — حجم التأرجح بمضاعفات ATR. القيمة المختبرة 1.5. أقل = نماذج أكثر وأصغر، أكثر = أقل وأكبر وأسوأ في القياس.
  • Ratio tolerance — سماحية النسبة. المختبَر ٥٪ نسبيّاً، وهو من الطرف المتشدّد؛ مؤشرات منتشرة تستعمل ١٠–١٥٪ فتجد ضعف العدد ويعني نصف المعنى.
  • Require the AB=CD projection — القراءة الصارمة لشرط التقارب عند كارني. مطفأة افتراضياً لأن اعتبارها شرطاً قاطعاً يجعل بعض النماذج مستحيلة هندسياً.
  • أي تغيير في هذه الثلاثة يجعل ما تراه مؤشراً آخر غير الذي تقول عنه الأرقام أعلاه.
